# Joi visual assets

## Cinematic README cover

`joi-cover.png` is a panoramic composition made from `joi-portrait.png` with
the built-in imagegen tool on 2026-10-30. It preserves Joi's face and pose,
extends the setting into a neon city, and incorporates the README wordmark.
The full composition fills the README width, replacing the separate title
and centered square photograph. The exact prompt is in `joi-cover.prompt.txt`.

`joi-signal.svg` and `joi-afterglow.svg` are original, code-native typography
and interface graphics. The signal graphic describes the project, rather than
reporting live server status. Its slow decorative pulse respects reduced motion.

## App portrait

`joi-portrait.png` is an edited version of the image supplied by the project
owner, depicting Joi / Ana de Armas in *Blade Runner 2049*. The edit crops the
frame, removes foreground distractions, and enhances the original neon palette.

Created with the built-in imagegen tool on 2026-10-29. The exact edit prompt is
saved in `joi-portrait.prompt.txt`. The source attachment was kept unchanged.
